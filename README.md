# Double A Insurance Website
This is a custom-built website for Double A Insurance.

## Features
- Responsive modern design
- Service-based layout (Auto, Home, Life, Business)
- Contact & Quote request form
- Mobile-friendly UI

## Tech Stack
- React (Vite)
- Node.js / Express (backend)
- Deployed with vercel

## Purpose
This project was built as part of a professional portfolio to show case real-world business website development.
